# Web 画面のリファクタリングレビューと使い勝手の見直し（2026-11-07）

対象は `apps/web` 全体（画面 7 枚、API クライアント、CSS）。API・DB は変更していない。
先に実装を読んで問題を洗い出し、そのうえで直した。各項目は「何が起きるか」を
再現テストか実ブラウザで確かめてから直している。

### 仕様との食い違い

- 学習のキーボード操作（`Space`、`1`〜`4`）が未実装だった（上位仕様 200 行目）。
- `responseDurationMs` をサーバは受け付けて保存するが、画面が送っていなかった。
  そのため「所要時間の目安」の材料が 1 件も溜まっていなかった。

### 構造の問題

- `DeckListScreen.tsx`（426 行）にウェルカム・ゲスト警告・アカウント管理・進捗・作成・一覧が同居。
- `['decks']` などのキャッシュ鍵が 7 画面に文字列で散らばり、B2〜B4 の取りこぼしを生んでいた。
- プロバイダ名の表が 2 か所（`DeckListScreen` と `MergeScreen`）で重複。
- 「URL を取ってブラウザごと遷移、失敗したら文言」という同じ処理が 3 回コピーされていた。
- 迷子の JSDoc が 2 か所（`downloadJson` の上に設定フォームの説明、`startMerge` の上に連携の説明）。
- 削除・連携解除・ログアウトの失敗が画面に出ていなかった。
- 初回の JS が 491 kB。一覧では使わない Markdown 描画も最初に読んでいた。

## 2. 直したこと

### 構造

- キャッシュ鍵と「何を変えたら何を捨てるか」を `api/query-keys.ts` に集約
  （`invalidateContent` / `invalidateStudyProgress` / `forgetSignedInData`）。
- `DeckListScreen` を `WelcomePanel` / `GuestNotice` / `AccountPanel` / `ProgressPanel` /
  `SignInButtons` に分割。プロバイダ定義は `auth/providers.ts` に一本化。
- OAuth 遷移を `useExternalRedirect` にまとめ、押下中は二重に押せないようにした。
  「戻る」で bfcache から復元されたときは押せない状態を解く。
- 画面単位の遅延読み込み。初回の JS は **491 kB → 244 kB（gzip 148 → 75 kB）**。
  古いチャンクが消えて読めない場合は、新設のエラー境界が再読み込みを促す。

### 学習画面

- `Space` / `Enter` で答え、`1`〜`4` で評価、`Ctrl`（Mac は `⌘`）+ `Z` で取り消し。
  入力欄・ボタン・リンクにフォーカスがあるときは横取りしない。ボタンにキーを添えて表示し、
  `aria-keyshortcuts` でも伝える。タッチ端末ではキー表示を隠す。
- 間隔を「10分後」「6時間後」「3日後」「1.5か月後」のように出す。
- 応答時間（カード表示から評価まで、上限 1 時間）を送る。再送では最初の測定値と鍵を使う。
- この回の学習枚数（「済 N」）と、終わったときの枚数を出す。
- 学習できるカードが無いときは「完了」ではなく理由とデッキへの導線を出す。
- 次のカードへ移ったとき、フォーカスが行き場を失っていればカードへ移す。

### デッキ詳細

- 並びを「カードを追加 → 取り込み・書き出し・設定（折りたたみ）→ カード一覧」に変えた。
  日常の操作を先頭に、めったに使わない設定を畳んだ。
- 追加後に表の欄へフォーカスを戻す。`Ctrl` / `⌘` + `Enter` で追加・保存。空白だけは追加不可。
- カードの削除は確認ダイアログをやめ、画面下に「元に戻す」を出す（ゴミ箱から戻せるため）。
- 編集は保存したら閉じる。変更が無ければ保存できない。`Esc` で閉じる。
- 取り込みにファイル選択を追加（拡張子から形式を判定）。形式ごとの見本と CSV の 1 行目の
  決まり（`front,back`）を表示。成功したら内容を空にして二重取り込みを防ぐ。
- 書き出しのファイル名から OS で使えない記号を除く。
- ページ送りで一覧の先頭へ戻し、読み込み中も前のページを残す（跳ねない）。
- カードが無いデッキでは「この単語帳を学習」を出さない。

### 単語帳一覧・その他

- 未ログインの最初の画面に「アカウントをお持ちの方」として Google / GitHub ログインを追加。
  別端末から戻った人がゲストを作らずに入れる（サーバはゲスト無しの完了に対応済み）。
- アカウントの連携・統合・解除・削除を「アカウントの管理」に畳み、ログアウトだけ常に出す。
- デッキを作ったらそのデッキの画面へ移る。空のデッキは「カードを追加」を主ボタンにし、
  今日やることがあるデッキだけ「学習する」を強調する。デッキ名もリンクにした。
- デッキ削除（確認は残す）の後にも「元に戻す」を出す。
- ゴミ箱で復元したら、何を戻したかを知らせる。
- 画面ごとのタイトル（React 19 の `<title>` 巻き上げ）。404 画面とエラー境界。
- 読み込み失敗時の「もう一度」ボタン。select / textarea / summary にもフォーカスリング。

## 3. 確認

- Biome、全パッケージの型検査、Web のテスト 113 件（変更前 77 件）、ビルド。
- 実ブラウザ（Chromium、API はモック）で、キー操作・間隔表示・応答時間の送信・
  画面タイトル・404 を確認。幅 320px / 375px で横スクロールが出ないことを確認。
- 追加した色の組み合わせはすべて WCAG の本文基準 4.5 以上（最小はキー表示の 5.11）。

## 4. 残したこと

- カード検索・絞り込み、デッキ間移動、タグ: API 側の追加が要るため手を付けていない。
- 所要時間の目安: 応答時間の記録をこの変更から始めた。溜まってから集計を足す。
- 存在しない `/assets/*.js` へ `index.html` を返す（SPA フォールバック）。デプロイ直後の古いタブは
  エラー境界の再読み込みで回復するが、`/assets/` 配下は 404 を返す方が原因が分かりやすい。
- Playwright E2E と axe の自動検査（上位仕様の要求）はまだ無い。
