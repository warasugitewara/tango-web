## 提案

### 1. 先にトークン層を作る（見た目は変えない）

色・間隔・字の段階を custom property へ抜くだけの変更を、単独で入れる。
配色を変える前にやる理由は、20 箇所のリテラルを抱えたまま色を変えると、
差分が巨大になって「何を変えたのか」が読めなくなるため。

見た目が変わらないので、既存の配色テストがそのまま通ることで担保できる。

### 2. 暖色ニュートラル＋深緑へ寄せる

| 役割 | 値 | 用途 |
| --- | --- | --- |
| 地 | `#eeeae3` | 画面の背景 |
| 面 | `#fbfaf7` | カード、パネル |
| 墨 | `#1b2420` | 本文 |
| 主 | `#2f5d4a` | 学習の導線、選択状態 |
| 主・濃 | `#1e3d31` | 主の上に載る文字、押下 |
| 補助 | `#6d7a72` | 副次情報 |
| 注意 | `#a23b22` | エラー、削除 |

生成物によくある「クリーム地＋テラコッタ」に寄せない。地は黄みを抑えた
灰みの暖色、差し色は仕様どおり深緑にする。

### 3. 主役を 1 つに絞る

学習画面のカードだけを主役にし、それ以外は静かにする。具体的には:

- 一覧の見出しは今の `4rem` から落とす。単語帳一覧は作業画面であって表紙ではない
- `TANGO / PRE-RELEASE` のような飾りラベル（`.eyebrow`）は撤去候補。
  字間を空けた英字の小見出しは、情報量が無いわりに視線を取る
- 進捗パネルは枠を薄くし、数字だけが読めれば足りる

### 4. 和文の組み

- 行長は全角 40 字程度で折る（現在は `.shell` の 1040px いっぱいまで伸びる）
- 見出しの `letter-spacing: -0.045em` は和文だと詰まりすぎる。0 付近へ
- Web フォントを入れるかは要判断（下記）

## 決めてほしいこと

1. **Web フォントを入れるか。** 入れると和文の印象は大きく変わるが、
   配信サイズが増え、依存も増える。入れないならシステムスタックの順序改善だけにする。
2. **暗色モードを作るか。** 今は無い。作るならトークン層の段階で 2 系統ぶん用意する。
3. **飾りラベル（`.eyebrow`）を撤去してよいか。**
4. 上の配色で進めてよいか。深緑の濃さの好みがあれば、そこだけ差し替える。

## やらないこと

- 承認前に一括置換しない。トークン抽出（1）だけは見た目が変わらないので、
  先に入れてもよいか含めて判断をもらう。
- 画面の情報設計そのものは変えない。今回は見た目の作り直しに限る。
  検索・デッキ間移動・設定画面などの**機能**追加は `pre-release-deferred.md` の管轄。
