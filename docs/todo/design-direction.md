## 仕様との食い違い

上位仕様（`docs/superpowers/specs/2026-08-01-...md` 195 行目）はこう書いている。

> warm neutral surfaces, a deep green accent … without copying the reference image's blue visual language

現状は**寒色の青**が主役で、指示と逆を向いている。急ぎで作った結果なので当然だが、
本番向けに作り直す最大の理由はここ。「なんとなく古い」ではなく、仕様と違う。

## 提案

### 1. 先にトークン層を作る（見た目は変えない）

色・間隔・字の段階を custom property へ抜くだけの変更を、単独で入れる。
配色を変える前にやる理由は、20 箇所のリテラルを抱えたまま色を変えると、
差分が巨大になって「何を変えたのか」が読めなくなるため。

見た目が変わらないので、既存の配色テストがそのまま通ることで担保できる。

### 2. 暖色ニュートラル＋深緑へ寄せる

| 役割 | 値 | 用途 |
| --- | --- | --- |
| 地 | `#eeeae3` | 画面の背景 |
| 面 | `#fbfaf7` | カード、パネル |
| 墨 | `#1b2420` | 本文 |
| 主 | `#2f5d4a` | 学習の導線、選択状態 |
| 主・濃 | `#1e3d31` | 主の上に載る文字、押下 |
| 補助 | `#6d7a72` | 副次情報 |
| 注意 | `#a23b22` | エラー、削除 |

生成物によくある「クリーム地＋テラコッタ」に寄せない。地は黄みを抑えた
灰みの暖色、差し色は仕様どおり深緑にする。

### 3. 主役を 1 つに絞る

学習画面のカードだけを主役にし、それ以外は静かにする。具体的には:

- 一覧の見出しは今の `4rem` から落とす。単語帳一覧は作業画面であって表紙ではない
- `TANGO / PRE-RELEASE` のような飾りラベル（`.eyebrow`）は撤去候補。
  字間を空けた英字の小見出しは、情報量が無いわりに視線を取る
- 進捗パネルは枠を薄くし、数字だけが読めれば足りる

### 4. 和文の組み

- 行長は全角 40 字程度で折る（現在は `.shell` の 1040px いっぱいまで伸びる）
- 見出しの `letter-spacing: -0.045em` は和文だと詰まりすぎる。0 付近へ
- Web フォントを入れるかは要判断（下記）

## 決めたこと（2026-09-26）

利用者から「見た目の刷新を進めて」と任されたため、次の前提で進めた。
どれも後から覆せる。

1. **Web フォントは入れない。** 外部からの読み込みと CSP の変更が要り、依存も増える。
   システムの和文スタックを整えるだけにした（本文は BIZ UDPゴシック系）。
2. **暗色モードは今回作らない。** 色はすべてトークンにまとめたので、
   `:root` の値を差し替えるブロックを足せば作れる。
3. **飾りラベルは撤去した。** 学習カードの `FRONT` / `BACK` は、どちらの面かを
   伝える意味があるので、和文の「表」「裏」に置き換えた。
4. **配色は上の案どおり。** 色の組み合わせはすべて WCAG の本文基準 4.5 以上を計算で
   確認した（無効表示だけ 3.09。無効表示は基準の対象外）。

## やらないこと

- 承認前に一括置換しない。トークン抽出（1）だけは見た目が変わらないので、
  先に入れてもよいか含めて判断をもらう。
- 画面の情報設計そのものは変えない。今回は見た目の作り直しに限る。
  検索・デッキ間移動・設定画面などの**機能**追加は `pre-release-deferred.md` の管轄。

## 実施内容（2026-09-26）

**1. トークン化（`8960533`、見た目は変えない）**
色の値を `:root` に集め、83 箇所を役割の名前で参照する形にした。jsdom は `var()` を
解決しないため、テスト用に展開するヘルパー（`apps/web/src/test/css.ts`）を足した。
学習リンクの配色テストは、特定の色との一致ではなくコントラスト比 4.5 以上で判定する。

**2. 配色と組み**
- 地を暖色の灰（`#eeebe4`）、差し色を深緑（`#2f5d4a`）へ。方眼の背景は撤去
- 見出しを作業画面の大きさ（最大 2.1rem）へ。和文なので字間は詰めない
- 数字の等幅フォントをやめ、`tabular-nums` で桁だけ揃える
- ブラウザ既定の青いリンクをやめる

**3. 主役は学習カードだけ**
紙の単語カードに寄せた。明朝体の見出し語、リングを通す穴、紙色の面。
一覧や設定まわりは静かにした。

**4. 目立ちすぎていた操作を下げた**
連携の解除とログアウトが全幅の主ボタンになっており、「学習する」より強かった。
アカウント欄を 1 行にまとめ、控えめなボタンにした。

**あわせて直した既存の不具合**
- 評価の「もう一度」だけを赤くする指定が一度も効いていなかった。`:first-child` の
  最初の子が `<legend>` だったため。`:first-of-type` に直した
- 明朝体には太字の字形が無く、全体で `font-synthesis: none` にしているため、
  カード裏の太字が消えていた。カードの中だけ合成を許した
